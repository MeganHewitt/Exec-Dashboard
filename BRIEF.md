# My Links - Project Brief
A personal link-in-bio page. One page, clean design, mobile first
I want to send people here from my social profiles

## Tech
- Pure HTML, CSS, and JavaScript - no frameworks, no build tools
- Single index.html file (CSS and JS can be seperate files)
Deploys to Vercel as static site

## Design 
- Centered card layout, max-width 480px
- My name as heading, short bio underneath
- Profile photo placeholder (circle, 120px)
- Light mode by default with light/dark toggle
- Smooth hover animations on the link buttons
- Google Font: Inter

## Links
Display there as stacked buttons, full width within the card
- Portfolio (https://example.com)
- Dribble (https://dribble.com)
- LinkedIn (https://linkedin.com)
- Email (mailto:me@example.com)

## Nice to have
- Subtle gradients or animated backgrounds
- Tomato girl summer motif
- Link buttons have icons (use simple SVG or emoji)
